# 萬鷺朝鳳生態解說手冊

「萬鷺朝鳳・茶山導覽」的包含項目寫著「萬鷺朝鳳生態解說手冊一份」（`src/lib/experiences.ts`、Sanity 導覽頁），
這個資料夾就是那本手冊的印刷原稿。**客人會帶回家、會拍照上網——它跟網站文案一樣是對外宣稱**，
改之前照 `docs/owner-source-quotes.md` 與本檔的規則走。

## 怎麼輸出

```bash
node docs/egret-handbook/build.mjs
```

需要本機裝有 Edge 或 Chrome（Windows 內建的 Edge 就可以）；找不到時用環境變數 `BROWSER` 指定路徑。
輸出會印出頁數與尺寸，**有頁面內容超出版心時會列出頁碼並以非零結束**（超出的部分會被直接裁掉，印出來就少一段字）。

QR code 要換連結時（`qrcode` 套件已在 node_modules）：

```bash
node -e "require('qrcode').toString('新的網址',{type:'svg',errorCorrectionLevel:'M',margin:0,color:{dark:'#2E3833',light:'#0000'}},(e,s)=>require('fs').writeFileSync('docs/egret-handbook/qr-guide.svg',s))"
```

## 印刷

- **A5（148×210mm）直式、16 頁、騎馬釘**。頁數是 4 的倍數，對折裝訂剛好不會多出空白頁。
- **刻意沒有出血**：每頁底色都是白的、照片四周留白，家用印表機與影印店都印得出來，裁切歪一點也不會露白邊。
- 影印店：直接給 `handbook.pdf`，說「A5 騎馬釘小冊、彩色、16 頁」。紙張請店家依預算建議；要耐翻就選厚一點的紙。
- 自己印：用 Adobe Acrobat Reader 的「小冊子」列印模式、A4 雙面，印完對折就是 A5 小冊（Reader 會自動排好頁序）。

## 內容規則（改稿前必讀）

1. **每一句自然知識都要有編號出處**，列在第 16 頁；**業主的觀察**（左往右飛、電線、盤旋較久、雨天）則以
   `docs/owner-source-quotes.md` 為依據，不另標編號，而是在文中寫明「我們在這裡看到的」。
   兩者要分開寫——第 2 頁向讀者承諾過「分開寫清楚」。
2. **因果解釋一律要有出處**（lessons 2026-09-23「歸巢」那一條）。查不到原因的，就放進第 9 頁「還沒有答案的問題」，不要補一個聽起來合理的解釋。
3. **不印會變動的商業資訊**：價格、方案、營業日、導覽期間都不寫——手冊印一次要用一整季，網站改得了、印好的改不了。
   唯一的例外是無人機禁航公告，因為它是每年都要提醒的安全事項，所以附上年份，並在封底註明「以主管機關最新公告為準」。
4. **講視野就要同一段交代電線**（owner-source-quotes §2.13）。第 12 頁的寫法是業主選定的 A 版口徑。
5. **照片裡的建築物不是自家的**（§2.1）。所有鳥的照片都是從信淳茶居往外拍的，圖說只描述畫面，不寫「我們家」。

### 刻意不寫的事

查證時看到、但**沒有可靠出處或有矛盾**的說法，都沒有寫進手冊。之後改稿不要再把它們加回來：

| 說法 | 為什麼不寫 |
|---|---|
| 黃頭鷺傍晚「歸巢」、太興是「棲地／中繼站」 | 所有官方與新聞來源都是南遷過境；業主確認「大多直接翻過山頭就走」（§2.7） |
| 「視野沒有電線」 | 業主更正：電線在右側與下方，拍鳥群基本上擋不到（§2.13） |
| IUCN 評等「無危」 | 那是拆分前的舊合併種評估；東方黃頭鷺這個新種查不到獨立評估。只寫臺灣鳥類紅皮書 |
| 跟著牛覓食「效率多 3.6 倍」、偏好「每分鐘 5–15 步」的牛群 | 常被引用，但原始論文（Heatwole 1965）無法調閱核對數字，只寫「1965 年就有論文研究」 |
| 求偶期「腳也會變紅」 | 來源互相矛盾（農業部寫腳趾黑色），只寫「部分個體嘴基到眼先轉紅」 |
| 遷徙是白天還是夜間飛、飛多高多快 | 查無黃頭鷺專屬的研究；一般候鳥的雷達數據不能套用 |
| 俗名「放牛鳥」 | 查無出處。有出處的別名只有「牛背鷺」（TaiCOL） |
| 灰面鵟鷹也會經過太興 | 查無任何紀錄；灰面鵟鷹的過境點在八卦山、滿州、觀音山 |
| 鳥群「從西伯利亞、日本、韓國」出發 | 只有單篇新聞這樣寫，沒有繫放或追蹤研究，手冊只寫「北方」 |
| 「1 天 5 萬隻」 | 新聞標題；手冊用有具名觀察者、有群數的那一筆（逾三萬隻），並註明是個人計數 |
| 「下午 4 點以後密度最高」 | 在 owner-source-quotes 找不到業主原話，只用已確認的「3 點到 6 點最壯觀」 |

## 查證時發現、網站還沒跟上的地方

- **在台身分**：攻略文「黃頭鷺是什麼鳥？」段寫「有沒有留鳥還待研究」（依據是農業部舊頁面）。
  但《2026 年臺灣鳥類名錄》已把黃頭鷺列為**留鳥（不普遍）＋夏候鳥＋冬候鳥＋過境鳥**。手冊用的是新名錄；
  攻略文要不要跟著改是業主的決定（在 Sanity，改了就直接上線）。
- **學名**：臺灣物種名錄 2026-08-12 起改為 *Ardea coromanda*。網站目前沒有寫學名，不受影響。

## 每年要換的東西

- 封面「2026 秋季版」與封底「2026 年 9 月初版」
- 第 13 頁無人機禁航公告：嘉義縣政府**每年**重新公告，日期範圍與罰則要照新公告改
- 第 15 頁赤腹鷹：那是 2026-09-17 單日的觀察紀錄，隔年可換成當年的新發現，或拿掉
- 第 3 頁數量：換成當年有具名觀察者的紀錄（沒有就保留舊的並寫明年份）
- 第 4 頁學名與身分：對一次最新版臺灣鳥類名錄與 TaiCOL
- 第 16 頁出處：每個網址重新連一次（2026-09-24 查證時已有兩個失效並換掉）
