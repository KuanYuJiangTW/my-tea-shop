## ADDED Requirements

### Requirement: 體驗詳細頁掛載開課請求入口
體驗詳細頁（`/experiences/[slug]`）SHALL 在月曆區塊之內、既有圖例與開課門檻提示之後，掛載開課請求入口。當該體驗的月曆在目前檢視的月份沒有任何場次時，入口 SHALL 以主要 CTA 樣式呈現（與「立即預約」同級的視覺重量）；有場次時則以次要樣式呈現，不得搶走既有場次的注意力。

#### Scenario: 該月有場次
- **WHEN** 使用者檢視的月份存在至少一個場次
- **THEN** 開課請求入口以次要樣式顯示於月曆下方，既有場次卡片仍是視覺主體

#### Scenario: 該月完全沒有場次
- **WHEN** 使用者檢視的月份沒有任何場次
- **THEN** 月曆區塊顯示以開課請求入口為主的 CTA，文案說明可指定日期申請開課

#### Scenario: 體驗未開放請求且該月無場次
- **WHEN** 該體驗 `accepts_requests = false` 且檢視月份無場次
- **THEN** 顯示既有的無場次說明，不顯示開課請求入口
